A portfolio and CV in one static page, set in an original illustrated landscape that tells the move from Honduras to Zaragoza. Spanish and English, light and dark.

## Worth a look

- **Ask my CV.** A BM25 search over the CV itself, built from the page's own markup when it loads. No model generates text: every answer quotes the CV.
- **Nothing from outside.** No framework, CDN, analytics or font service: one HTML file, one script and four self-hosted fonts.
- **Paints before the script.** `app.js` is requested after the first frame. The cover is already in the visitor's language, and nothing moves when the script arrives.
- **The print stylesheet is the PDF.** Both downloadable CVs come from the page's own print rules, one A4 page each.

## Quality

Every push to `main` runs the full gate before deploying, and the deploy only runs if it passes:

- **Playwright:** end-to-end journeys and layout at six screen sizes.
- **axe-core:** zero accessibility violations.
- **Lighthouse:** 100 in every category, on mobile and desktop.
- **V8 coverage:** 100% of the page's JavaScript. The badge above shows the run that gated the live site.

```bash
npm ci && npx playwright install --with-deps chromium
npm run qa        # tests + coverage + Lighthouse
```

## Run and edit

```bash
python3 -m http.server 8000   # http://localhost:8000
```

- **Content:** Spanish lives in `index.html` and English in `app.js`; the first screen's English is in `EN_TOP` inside `index.html`.
- **Landscape:** generated by `tools/scene.py`.
